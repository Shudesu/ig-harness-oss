Solution
IG Harness

A社 / B社の上位互換を、完全無料・オープンソースで。

IG Harness は、Instagram DM 自動化のすべての機能を備えた OSS CRM プラットフォーム。Cloudflare Workers で動作し、サーバー代 0 円。MIT ライセンスで商用利用も完全自由です。

Quickstart

1コマンドで完全セットアップ

CLI が Cloudflare 認証からデプロイまで全部やります。所要時間 約 5 分。

npx create-ig-harness

CLI がやること：

  • ✅ Cloudflare 認証（wrangler login）
  • ✅ D1 DB + R2 バケット作成・スキーマ適用
  • ✅ Worker + 管理画面デプロイ
  • ✅ Instagram credentials 登録
  • ✅ Meta Webhook 連携ガイド表示
  • ✅ Owner ユーザー自動作成

必要なもの：Cloudflare アカウント（無料）、Instagram プロアカウント、Node.js 22+

Standard Access

Meta 審査なしで、
ここまで動きます。

Instagram Messaging API は、自分が所有・管理するプロアカウントであれば Standard Access（Meta App Review 不要）でほぼすべての機能が動作します。

IG Harness のコメント返信は @mention 付きトップレベル投下方式で実装されており、Standard Access のまま動きます。

Advanced Access が要るのは：ネストされた本物のスレッド型 reply、または自分が管理しない他社アカウントをホストするマルチテナント運用のみ。通常の個人・法人運用には不要。

FAQ

よくある質問

本当に無料ですか？後から課金されませんか？
IG Harness が課金することは一切ありません。永久に0円です。サーバーは Cloudflare Workers を利用しており、無料枠でそのまま動作します。Cloudflare 側の従量料金が発生する場合がありますが、それは Cloudflare への支払いであり、IG Harness への課金ではありません。
エンジニアじゃなくても使えますか？
管理画面はブラウザで操作できる直感的な UI です。初期セットアップには Cloudflare アカウントの作成など技術的な手順がありますが、npx create-ig-harness の 1 コマンドと動画ガイドで約 5 分で完了します。
A社 から乗り換えられますか？
はい。コメント→DM・フォローゲート・ステップ配信・リッチメッセージなど A社 の主要機能をすべてカバーし、API 公開・Claude Code 対応・LINE クロスリンクなど A社 にはない機能も搭載しています。
Meta 審査（App Review）は必要ですか？
自分が所有・管理するプロアカウントの運用なら Standard Access で動作し、App Review は不要です。他社のアカウントをホストするマルチテナント運用の場合のみ Advanced Access が必要です。
セキュリティは大丈夫ですか？
データはあなた自身の Cloudflare D1 データベースに保存されます。第三者サーバーを経由しないため、既存 SaaS よりも強固なデータ管理権限を持ちます。オープンソースなのでコードの透明性も保証されています。
なぜ無料で公開するのですか？
AI の進化により、あらゆる SaaS は民主化される時代が来ています。その流動性を高め、誰もが自由にツールを使える世界を実現するために IG Harness は無料で公開しています。LINE Harness・X Harness に続く「The Harness」第三弾として、SNS 自動化のすべてを0円で揃えられる時代を目指しています。
