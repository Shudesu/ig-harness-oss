# IG Harness 運用マニュアル

ManyChat / Inflact から脱却し、自前ホスト OSS で Instagram の DM 自動化・LP 誘導・LINE 連携を回すためのマーケター向け運用書です。

OSS 本体（コード・最低限のセットアップ手順）は無料で公開されていますが、本マニュアルでは「どう設計すれば獲得できるか（How / Why）」まで踏み込みます。第1〜3章および第7章は無料公開、第4〜6章は **🔒有料章** として段階的に深掘りします。

## 無料 / 有料の境界

- **無料**: 「ボタンを押すと何が起きるか」（What）— 第1章・第2章・第3章・第7章
- **🔒有料**: 「どう設計すれば獲得できるか」（How / Why）— 第4章・第5章・第6章

無料章だけでも OSS の動作原理は理解できます。実運用で「数字を作る」フェーズに入ったら、有料章で設計の深部に踏み込んでください。

## このマニュアルの読み方

1. まず **第1章** で「これが何を解決する OSS なのか」を掴む
2. **第2章** でセットアップを通し、自分のアカウントで触れる状態にする
3. **第3章** で各機能の挙動を確かめる（What の習得）
4. 実運用に入ったら **第4〜6章** で設計の深部に進む（有料）
5. 困ったら **第7章** で切り分け
