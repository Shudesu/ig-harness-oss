# 第7章 トラブルシュート

> 【tier: 無料】Standard Access の壁・商標苦情・送信不能など、IG Harness 運用で遭遇しやすい事象の切り分けと復旧。

## 章の目的
- 「動かない」事象を一次切り分けし、ログ／設定／Meta 側のどこに原因があるか判別できる
- Standard Access 由来の制約（comment reply 不可など）を「仕様」として正しく扱える
- 商標苦情・アカウント制限が来た際の初動対応を持っておく

## 想定読者
- 本番運用中に問題が発生したすべての運用者
- セットアップ中につまずき、原因が切り分けられない読者

## 目次
- 7.1 Standard Access の壁 — comment reply が動かない／投稿コメントへ反応しない（参照: feedback-ig-harness-standard-access-limit）
- 7.2 DM が届かない／既読がつかない（送信レート、24時間ルール、ユーザー側設定）
- 7.3 Webhook が来ない／途中で止まる（Meta アプリ設定、Worker ログ、再購読手順）
- 7.4 商標苦情・アカウント制限が来たときの初動（停止判断、文面修正、再開判断）
- 7.5 ログ・メトリクス・Cloudflare ダッシュボードの読み方（一次切り分けの基本動線）
