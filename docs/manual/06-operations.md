# 第6章 運用フロー 🔒

> 【tier: 🔒有料】複数キャンペーンを並走させながら、日次／週次／月次でアカウントを健全に育てるための運用設計。

## 章の目的
- 日次・週次・月次の運用ルーチンをそのまま自分のチームに移植できる
- DM 上限・送信レート・スパム判定リスクを意識した送信制御を組める
- データを見て改善する週次レビューフォーマットを持ち帰れる

## 想定読者
- 第5章まで完了し、複数キャンペーンを実運用に乗せたい人
- 一人運用 → チーム運用へスケールしたい運用責任者

## 目次
- 6.1 日次オペレーション（送信状況確認、エラー監視、DM 上限管理）
- 6.2 週次レビュー（KPI チェック、ゲート通過率、CV 率の見方）
- 6.3 月次の棚卸し（不発キャンペーンの停止判断、文面・クリエイティブ更新）
- 6.4 アカウント健全性の維持（送信レート、スパム判定、シャドウバン回避）
- 6.5 チーム運用への展開（権限分離、デプロイ承認、ログ閲覧範囲）

## 前提
- 第1〜5章を読了済み
- 1本以上のキャンペーンを本番で稼働させた経験がある

## 次の章
- 第7章では、よくあるトラブルとその切り分け／復旧手順をまとめる。
