# 新しいMetaアプリでつなぐ（統合ログイン）

2026年10月末ごろから、新しく作ったMetaアプリでは「InstagramログインによるAPI設定」が出なくなり、「統合ログインを使用したAPI設定」だけが選べるようになりました。この章は、その新しいアプリでIGハーネス（The Harness Cloud を含む）にInstagramアカウントをつなぐ手順です。エンジニアでなくても進められるように書いています。

- 以前からあるMetaアプリ（「InstagramログインによるAPI設定」が出るアプリ）を使い続ける場合は、この章は不要です。[セットアップ](./02-setup.md) のとおりに進めてください。
- 画面の文言はMeta側の変更で少し変わることがあります。見当たらないときは近い名前のボタンを探してください。
- 📷 マークの位置にスクリーンショットを差し込む予定です。

## この方式のポイント（最初に知っておくこと）

| 項目 | 以前の方式（Instagramログイン） | 新しい方式（統合ログイン） |
|---|---|---|
| トークンの先頭 | `IGAA…` | `EAA…` |
| Facebookページ | 不要 | 不要 |
| ビジネスポートフォリオ | 不要 | **必須**（アプリをポートフォリオにつなぐ） |
| トークンの期限 | 60日（IGハーネスが自動で延長） | 設定しだい。初期設定のシステムユーザートークンは無期限。IGハーネスは延長処理をしません |
| IGハーネスでの見え方 | 「Instagramログイン」 | 「統合ログイン」 |

IGハーネスはトークンの先頭を見て、`EAA…` なら自動で統合ログインとして扱います。どちらの方式かを自分で選ぶ必要はありません。

## 用意するもの

- Instagramのプロアカウント（ビジネスまたはクリエイター）。個人アカウントのままだと接続できません。
- Metaのビジネスポートフォリオ（旧ビジネスマネージャ）。Instagramアカウントがそのポートフォリオに入っていること。
- IGハーネスの管理画面に **owner（オーナー）** でログインできること。
- IGハーネスのWebhook URL と 検証トークン（セットアップ完了時に表示されたもの。Cloud の場合は開通メールに記載）。

## 手順1. Metaアプリを作る

1. [Meta for Developers](https://developers.facebook.com/apps/) を開き「アプリを作成」を押します。
2. ユースケースで「**Instagramでメッセージとコンテンツを管理**」を選びます。
3. アプリ名を入れて作成します。

📷 スクショ1: ユースケース選択画面（「Instagramでメッセージとコンテンツを管理」にチェック）

## 手順2. ビジネスポートフォリオをつなぐ

1. 作ったアプリのユースケース「Instagramでメッセージとコンテンツを管理」の「カスタマイズ」を開きます。
2. 「統合ログインでInstagram APIの設定を使用するには、ビジネスポートフォリオを選択する必要があります」と出たら、案内に従ってビジネスポートフォリオを選びます。
3. 選び終わると「InstagramログインによるAPI設定は、新しいアプリでは利用できません。代わりに統合ログインを使用したAPI設定を使用します」と表示されます。これで正しい状態です。

📷 スクショ2: ビジネスポートフォリオ選択の案内
📷 スクショ3: 「統合ログインを使用したAPI設定」の画面

## 手順3. 「設定（configuration）」を作る

「統合ログインを使用したAPI設定」の画面にある手順1「ビジネス向けFacebookログインの設定を作成」を進めます。

1. ログインのバリエーションは「一般」のままで大丈夫です。
2. アクセストークンは「**システムユーザーアクセストークン**」（無期限）を選びます。初期値のままで大丈夫です。
3. ビジネスアセットは「**Instagramアカウント**」を必ず選びます（広告アカウントは不要）。
4. 権限は少なくとも次の4つにチェックを入れます。
   - `instagram_basic`（必須）
   - `instagram_manage_messages`（DMを送る）
   - `instagram_manage_comments`（コメントを読む・返信する）
   - `instagram_content_publish`（投稿予約を使う場合）
5. 保存します。

📷 スクショ4: 設定作成画面（トークン種別＝システムユーザー、アセット＝Instagramアカウント）
📷 スクショ5: 権限のチェック欄

## 手順4. Instagramアカウントをテスターに追加してトークンを作る

1. アプリの「アプリの役割」→「役割」で、つなぎたいInstagramアカウントを「**Instagramテスター**」に追加します。
2. Instagramアプリ（またはinstagram.com）の「設定」→「ウェブサイトのアクセス許可」→「テスターへの招待」で招待を承認します。
3. 「統合ログインを使用したAPI設定」の手順2で、アカウントの横の「**トークンを生成**」を押します。
4. 表示されたトークン（`EAA…` で始まる長い文字列）をコピーします。**このトークンは他人に見せたり、チャットに貼ったりしないでください。**
5. 同じ行に出ている **InstagramのID**（数字だけの長い番号。例: `1784…`）とユーザー名もメモしておきます。

📷 スクショ6: Instagramテスターの追加画面
📷 スクショ7: 「トークンを生成」ボタンと、IDが表示されている行（トークン部分は隠す）

## 手順5. MetaアプリにWebhookを設定する

「統合ログインを使用したAPI設定」の手順3「Webhooks」を開きます。

1. コールバックURL に IGハーネスのWebhook URL（`https://…/webhook`）を入れます。
2. 認証トークン（verify token）に IGハーネスの検証トークンを入れます。
3. 「確認して保存」を押します。
4. フィールドの一覧で、次の4つを「購読（Subscribe）」にします。
   - `messages`
   - `messaging_postbacks`
   - `messaging_referral`
   - `comments`

📷 スクショ8: Webhooks のコールバックURL入力欄
📷 スクショ9: 購読フィールドの一覧（4つがONの状態）

> 署名の確認には、このアプリの「App Secret」（アプリの設定 → ベーシック）を使います。Cloud以外で、管理画面に追加するアカウントが既定とは別のMetaアプリの場合は、手順6の「別 Meta App を使う場合」にこの App Secret を入れてください。

## 手順6. IGハーネスの管理画面にアカウントを追加する

1. IGハーネスの管理画面にownerでログインし、「設定」→「Instagram アカウント」を開きます。
2. 「アカウントを追加」の欄で、
   - **アクセストークン** に手順4でコピーした `EAA…` を貼ります。
   - **IG User ID** に手順4でメモした数字のIDを入れます（空欄でも自動で探しますが、見つからないときは入力が必要です）。
   - 既定とは別のMetaアプリの場合だけ「別 Meta App を使う場合」を開き、App Secret と検証トークンを入れます。
3. 「アカウントを追加」を押します。IGハーネスがMetaに問い合わせて、IDとユーザー名が正しいかを確かめてから保存します。
4. 一覧に追加したアカウントが出て、「状態」に **統合ログイン** と表示されれば成功です。トークン期限の欄は「自動更新なし」と表示されます。

📷 スクショ10: アカウント追加フォーム（トークン欄は伏せる）
📷 スクショ11: 一覧に「統合ログイン」バッジが付いた状態

## 手順7. Webhook購読ボタンを押す

1. 一覧の追加したアカウントの行で「**Webhook購読**」を押します。
2. 「Webhook購読を設定しました（messages, messaging_postbacks, messaging_referral, comments）」と緑色で出れば完了です。

📷 スクショ12: 「Webhook購読」ボタンと成功メッセージ

これを押さないと、Meta側でWebhookを設定していても、このアカウントのDMやコメントがIGハーネスに届きません。

## 手順8. 動作を確かめる

1. サイドバーで追加したアカウントに切り替えます。
2. 別のInstagramアカウント（テスターに追加したもの）から、そのアカウントにDMを1通送ります。チャット画面に届けば受信OKです。
3. キャンペーンを1つ作り、対象の投稿にキーワードをコメントして、DMが返ってくるか確かめます。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 追加時に「No Instagram professional account was found…」と出る | IG User ID 欄に、Meta画面に出ている数字のIDを入れて、もう一度追加する |
| 追加時に「Token belongs to a different Instagram user_id」と出る | 入れたIDとトークンのアカウントが違う。手順4の同じ行のIDを入れ直す |
| 追加時に「Instagram token validation failed (code 190)」と出る | トークンが間違っているか失効している。手順4でトークンを作り直す |
| 「(#10) … not business or creator」系のエラー | Instagramアカウントがプロアカウントになっていない |
| Webhook購読で「code 200」や権限のエラー | 手順3の権限（`instagram_manage_messages`、`instagram_manage_comments`）が設定に入っているか確認し、トークンを作り直して「トークン更新」で貼り替える |
| DMやコメントに反応しない | 手順5の購読フィールド4つ、手順7のボタン、テスター承認の3点を確認 |
| 他人のアカウント（お客さまのアカウント）で使いたい | アプリレビュー（Advanced Access）とビジネス認証が必要。自分のアカウントだけならStandard Accessのままで使える |
| しばらくして急に動かなくなった | ビジネスポートフォリオからアプリを外した、またはInstagramアカウントを別のポートフォリオに移すとトークンが無効になる。手順4でトークンを作り直し、一覧の「トークン更新」で貼り替える |

## 補足（技術者向け）

- 統合ログインのアカウントは `graph.facebook.com` を使い、IGのIDを明示して呼び出します（`/me` は Instagram アカウントではなくシステムユーザーを指すため）。DM・private reply は `/{ig-user-id}/messages`、Webhook購読は `/{ig-user-id}/subscribed_apps` です。
- IG User ID を空欄にした場合は `/me/assigned_instagram_accounts` → `/me/accounts`（Facebookページ連携）の順に探します。候補が1件のときだけ自動で選びます。
- 既存アカウントは「Instagramログイン」のまま動作は変わりません。既存アカウントを統合ログインへ切り替えるときは、「トークン更新」で `EAA…` のトークンを貼れば切り替わります。
- 統合ログインのトークンは `refresh_access_token` での延長を行いません。失効したら定期チェックで「要再接続」になります。
- 初回セットアップのウィザード（`pnpm deploy:setup`、セルフホスト用）は現時点では Instagram ログインのトークンだけを確認します（未対応）。The Harness Cloud は管理画面からアカウントを追加するので、この章の手順6〜7で接続できます。
- 仕様の出典は Meta 公式「Instagram API with Unified Login」（https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-unified-login/ ）と Webhook 設定（https://developers.facebook.com/documentation/instagram-platform/webhooks/setup ）です。
